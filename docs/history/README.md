# History

Archived planning documents from the upstream `repository-harness` project
(`PHASE2.md`–`PHASE5.md`). They describe how the Harness CLI and its
observability / verification / evolution features were scoped and built.

They are kept for provenance and for understanding why the CLI works the way it
does. They are **not** operating instructions for this repo. Current operating
docs are `AGENTS.md`, `docs/HARNESS.md`, `docs/FEATURE_INTAKE.md`,
`docs/CONTEXT_RULES.md`, `docs/ARCHITECTURE.md`, and `docs/QUICKSTART.md`.
